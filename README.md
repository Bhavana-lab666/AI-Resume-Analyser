# AI Resume Screening & Job Recommendation System

## 📌 Project Overview

An AI-based Resume Screening and Job Recommendation System that analyzes resumes using NLP and Machine Learning techniques.

## 🚀 Features

- Resume PDF text extraction
- Resume skill analysis
- Job recommendation
- Skill gap analysis
- Resume-job similarity matching
- Streamlit web interface

## 🛠️ Technologies Used

- Python
- Streamlit
- Pandas
- NumPy
- Scikit-learn
- NLP
- PyPDF2
